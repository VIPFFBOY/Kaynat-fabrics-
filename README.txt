# Kaynat Fabrics — Women's Ethnic Wear Store

Files:
- index.html — catalogue / e-commerce homepage
- payment.html — separate UPI payment page
- style.css — responsive design
- script.js — products, search, filters, cart and checkout

UPI ID currently configured: 9508229704@pthdfc

How to publish:
1. Upload all four files to your GitHub repository.
2. Keep `index.html` as the GitHub Pages homepage.
3. Enable GitHub Pages from Settings → Pages.
4. The homepage opens as the catalogue. Checkout goes to `payment.html`.

Replace the sample products in `script.js` with your real products and prices.
